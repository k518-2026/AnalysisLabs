データ分析ラボ

ブラウザーだけで動く、統計解析と質的分析のツール集

教育・心理・社会調査のデータを、インストール不要・データ送信なしで分析できるツール集です。論文の記述例と、同じ計算を再現する R コードも出力します。

  • ブラウザーだけで動くインストールもアカウント登録も要りません。入力したデータは端末の外に送られません。
  • 論文にそのまま近づける多くのツールが、結果の読み方・論文の記述例・同じ計算を再現する R コードを出します。
  • 同じ手順で使えるどのツールも「読み込む → 設定する → 実行する → 書き出す」の順に並んでいます。

01

比べるCompare

群や条件のあいだに差があるかを調べる。

  • データ比較・自動分析

    Auto Compare

    2群以上の比較で、正規性に応じた検定を自動で選び、記述統計・図・APA形式の記述まで出す。

     ツールを開く →

  • カテゴリ分析

    Categorical Analysis

    人数・頻度のデータを、頻度論とベイズ統計の両方で読む。二項検定から対数線形モデルまで7種類。

     ツールを開く →

  • カテゴリデータ検定

    Contingency Tests

    分割表を入れるだけで、カイ二乗・Fisher・McNemar・二項検定と、ベイズファクター・記述例を出す。

     ツールを開く →

  • ノンパラメトリック検定

    Nonparametric Tests

    順位にもとづく検定を、データ入力から論文の記述例・R コードまでひと続きで。

     ツールを開く →
02

関係を見るRelate

変数どうし、人どうしのつながりを数値と図にする。

  • 相関分析と散布図

    Correlation & Scatter

    相関行列・散布図・解釈の文章を一度に。正規性に応じて Pearson と Spearman を使い分ける。

     ツールを開く →

  • ネットワーク分析ラボ

    Social Network Analysis

    「誰と誰がつながっているか」を貼るだけで、中心性・コミュニティ・構造指標を図と表と解説に。

     ツールを開く →
03

説明・予測するExplain & Predict

結果を説明する要因を探し、予測や効果の推定を行う。

  • 回帰分析・自動判定

    Auto Regression

    目的変数と説明変数の型から、重回帰・ロジスティック回帰・数量化I類／II類を自動で判定する。

     ツールを開く →

  • 数量化理論

    Hayashi Quantification

    林知己夫の数量化I類〜IV類。カテゴリーデータで回帰・判別・対応分析・多次元尺度構成を行う。

     ツールを開く →

  • 質的比較分析（QCA / fsQCA）

    Qualitative Comparative Analysis

    少数事例の「条件の組み合わせ」と結果の関係を、真理表と論理式で示す。crisp・多値・ファジィ集合に対応。

     ツールを開く →

  • 決定木ラボ

    Decision Tree (CART)

    分類と回帰の決定木を育て、あたり具合・変数の重要度・ルールを確かめる。

     ツールを開く →

  • 混合モデルラボ

    Linear Mixed Models

    生徒が学級に、測定が個人に入れ子になったデータを、固定効果とランダム効果に分けて推定する。

     ツールを開く →

  • 傾向スコアマッチング

    Propensity Score Matching

    観察データで、処置を受けやすさが近い者どうしを組にして、処置の効果を推定する。

     ツールを開く →
04

構造と測定Structure & Measurement

多くの変数の背後にあるまとまりや、測定の精度を調べる。

  • クラスター分析ラボ

    Cluster Analysis

    階層的クラスター分析と k-means 法で、似たものどうしをまとめる。樹形図の切断線はドラッグで動く。

     ツールを開く →

  • 主成分分析ラボ

    Principal Component Analysis

    たくさんの変数を少ない軸にまとめ直す。固有値からバイプロット、記述例まで。

     ツールを開く →

  • 因子分析ラボ

    Factor Analysis (EFA & CFA)

    前提の確認、因子数の決定、探索的因子分析、確認的因子分析、記述例と R コードまで。

    マニュアルありツールを開く →

  • 構造方程式モデリング・ラボ

    Structural Equation Modeling

    lavaan と同じ書き方でモデルを組み、推定・パス図・診断・群の比較まで。

    マニュアルありツールを開く →

  • 一般化可能性理論ラボ

    Generalizability Theory

    得点のばらつきを人・条件・誤差に分け（G研究）、項目数や評価者数を変えた信頼性を試算する（D研究）。

    マニュアルありツールを開く →

  • 項目反応理論ラボ

    Item Response Theory

    回答データから、項目の性質と受験者の特性値を同じ物差しで推定する。1PL・2PL・3PL・段階反応モデル。

     ツールを開く →
05

質的・テキストQualitative & Text

自由記述・逐語録・インタビューを整理し、語の関係を見る。

  • 共起ネットワーク比較ラボ

    Co-occurrence Network Comparison

    2つのテキストの共起ネットワークを描き、共通の語・固有の語を色分けして比べる。

     ツールを開く →

  • 対応テキストマイニング

    Paired Text Mining

    同じ人の事前・事後の自由記述を ID で突き合わせ、消えた語・現れた語と共起ネットワークを示す。

     ツールを開く →

  • 授業発話分析ラボ

    Classroom Discourse Analysis

    授業の逐語録から、フランダース相互作用分析・発問の分類・IRF 連鎖・語彙を数えて見せる。

     ツールを開く →

  • QDA ワークベンチ

    QDA Workbench

    インタビューや自由記述のコーディングから、カテゴリー化、行列、図、ストーリーラインまで。

     ツールを開く →

  • SCAT分析ラボ

    Steps for Coding and Theorization

    大谷尚の SCAT の分析フォームで、4ステップのコーディングからストーリー・ライン、理論記述までを進める。

     ツールを開く →

  • QDA-Lite

    QDA Lite

    テキストにコードを付けて、対象者ごとに集計する軽量版。感情辞書による抽出も。

     ツールを開く →

    Bootstrap Resampling

    データを復元抽出で繰り返し、平均値・中央値・標準偏差の信頼区間を経験的に求める。

  • メタ分析ラボ

    Meta-Analysis

    複数の研究の効果量をそろえて統合し、森林プロット・異質性・出版バイアスを吟味する。
