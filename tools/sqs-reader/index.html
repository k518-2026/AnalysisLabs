SQS マーク読み取り

SQS Mark Reader

スキャンした調査票の画像からマークを読み取り、集計用の CSV を作る。

ツールを開く

01概要

SQS ソースエディタ Web で作った調査票と、回答をスキャンした画像を読み込み、マークを認識して表データにします。要確認の箇所を画面で確かめ、横持ち・縦持ちの CSV と集計結果を出します。

02できること

  • 調査票（.sqs）とスキャン画像の読み込み
  • マーク認識と閾値などの設定
  • ページの確認、要確認の一覧、自由記述欄の一覧
  • 表データ CSV（横持ち・縦持ち）、集計結果、マスタの保存
  • 動作確認用のテスト画像の作成

03使い方

  1. 調査票を開く
  2. スキャン画像を追加する
  3. 読み取りを開始する
  4. 要確認の箇所を確かめて CSV を書き出す

テスト画像を作る機能があります。

04読み込めるデータ

.sqs ファイルと、回答をスキャンした画像。

05書き出せるもの

  • 表データ CSV（横持ち・縦持ち）
  • 集計結果
  • マスタ（JSON）

06注意

  • 「SQS ソースエディタ Web」で印刷した調査票を使ってください。
  • バーコードの読み取りと Excel 形式の書き出しには対応していません。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
