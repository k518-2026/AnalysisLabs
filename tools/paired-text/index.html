質的・テキスト

対応テキストマイニング

Paired Text Mining

同じ人の事前・事後の自由記述を ID で突き合わせ、消えた語・現れた語と共起ネットワークを示す。

ツールを開く

01概要

同じ回答者から2時点で集めた自由記述を、ID で対応づけて比べます。表記ゆれのある ID も近い順に照合し、事前・事後の共起ネットワーク、語ごとの増減、ID ごとの変化を出します。

02できること

  • ID の照合（表記ゆれを編集距離で許容。近似一致の組は色で示し、使う／使わないを選べる。英字の部分が違う組は最初は使わない）
  • 図の配置を選べる（5区画で整列・自動・まとまり別・同心円・円形）。語は枠に収まり、ラベルが重ならない
  • 事前・事後・対応比較の共起ネットワーク（PNG・高解像度）
  • 語の変化の判定：事後のみ／増加／変化なし／減少／事前のみ
  • ユーザー辞書・除外語、Jaccard 係数のしきい値
  • 結果のまとめ、論文の記述例、R（RMeCab・igraph/ggraph）のコード

03使い方

  1. 事前・事後のテキストを「ID,テキスト」の形で入れる（またはサンプル）
  2. 品詞と共起ネットワークのしきい値を決めて「解析を実行」
  3. ID の対応を確認する
  4. 図・表・記述例・R コードを確認する

サンプルデータがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

1行1件で「ID,テキスト」の形式。CSV のドロップにも対応。

05書き出せるもの

  • 共起ネットワーク（PNG）
  • 語の変化の表（CSV）
  • ID ごとの表（CSV）
  • 論文の記述例
  • R コード（.R）

06注意

  • 高精度モード（kuromoji.js）を選んだときだけ、辞書ファイルを CDN から取得します。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
