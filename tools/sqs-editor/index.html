SQS ソースエディタ Web

SQS Source Editor

マークシート式の調査票を作り、印刷用の PDF を組む。SQS の編集ソフトのブラウザー版。

ツールを開く

01概要

マークシート式の調査票を、設問を追加しながら作ります。印刷原稿のプレビューを見ながら書式を整え、印刷用の PDF、HTML フォーム、設問一覧の CSV を書き出します。オープンソースの SQS（Shared Questionnaire System）の SourceEditor をブラウザーで動くように作り直したものです。

02できること

  • 雛形からの新規作成、.sqs ファイルの読み込み・保存
  • 設問の追加と編集、元に戻す・やり直し
  • 書式設定と印刷原稿のプレビュー
  • 印刷原稿 PDF、HTML フォーム、設問一覧 CSV

03使い方

  1. 雛形を選ぶか .sqs を開く
  2. 設問を追加・編集する
  3. 書式を整える
  4. 印刷原稿 PDF を書き出して印刷する

雛形があります。

04読み込めるデータ

.sqs ファイル（または新規作成）。

05書き出せるもの

  • .sqs
  • 印刷原稿 PDF
  • HTML フォーム
  • 設問一覧 CSV

06注意

  • 読み取りには「SQS マーク読み取り」を使います。元の Java 版で印刷した PDF とは行送りがずれることがあります。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
