質的・テキスト

QDA ワークベンチ

QDA Workbench

インタビューや自由記述のコーディングから、カテゴリー化、行列、図、ストーリーラインまで。

ツールを開く

01概要

逐語録・フィールドノート・自由記述を読み込み、コードを付け、カテゴリーにまとめ、行列や図で関係を見ながら結果を書く、質的研究の一連の作業をひとつの画面で行います。メモと省察の記録も残せます。

02できること

  • 読み込み：.txt／.md／.csv／.tsv／.vtt／.srt／.docx、CSV の列は属性に
  • 発言者別・見出し行・辞書による自動コーディング、検索と一括コーディング、コードクエリ
  • カテゴリー、コードブック（CSV／Markdown）、行列コーディング（カイ二乗検定つき）
  • ワードクラウド、ワードツリー、共起ネットワーク、コードの樹形図、資料ポートレイト、カテゴリー関連図
  • コードメモ・理論メモ・方法論メモ、省察、ストーリーラインとレポート

03使い方

  1. 資料を読み込み、通読する
  2. コーディングする
  3. カテゴリーと行列で整理する
  4. 図とストーリーラインで結果をまとめる
  5. メモを残し、記述例を確認する

04読み込めるデータ

.txt／.md／.csv／.tsv／.vtt／.srt／.docx、または保存したプロジェクト（.json）。

05書き出せるもの

  • プロジェクト（.json）
  • コードブック（CSV／Markdown）
  • 図（PNG）
  • レポート

06注意

  • 作業内容はこまめにプロジェクト（.json）として保存してください。
  • 高精度モード（kuromoji.js）を選んだときだけ、辞書ファイルを CDN から取得します。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
