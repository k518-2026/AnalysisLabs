項目反応理論ラボ

Item Response Theory

回答データから、項目の性質と受験者の特性値を同じ物差しで推定する。1PL・2PL・3PL・段階反応モデル。

ツールを開く

01概要

2値（正誤）や多値（5件法など）の回答データから、項目の困難度・識別力と、受験者の特性値を推定します。項目特性曲線や情報量の図、群による特異項目機能（DIF）も確かめられます。

02できること

  • 1PL・2PL・3PL・段階反応モデル
  • 周辺最尤法（EM アルゴリズム＋ガウス求積）
  • 特性値の推定：EAP／最尤推定
  • 逆転項目の指定、DIF の検討
  • 項目のパラメータ、項目特性曲線

03使い方

  1. 回答データを読み込むか貼り付ける（または例を入れる）
  2. 項目・受験者 ID・群・逆転項目を指定する
  3. モデルと推定法を選ぶ
  4. 「推定を実行する」を押す

2値データと5件法データの例があります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV・タブ区切り（1行が1人、1列が1項目、1行目は項目名）。2値は 0/1、多値は 1〜5 などの順序尺度。空欄・NA は欠測。

05書き出せるもの

  • 項目のパラメータ
  • 特性値
  • 項目特性曲線などの図

06注意

  • 最尤推定では、満点・0点の受験者の特性値は推定できません（EAP を使うと全員に値が出ます）。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
