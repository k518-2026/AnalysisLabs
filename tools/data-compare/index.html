比べる

データ比較・自動分析

Auto Compare

2群以上の比較で、正規性に応じた検定を自動で選び、記述統計・図・APA形式の記述まで出す。

ツールを開く

01概要

CSV を読み込み、比べたい値と群（または対応のある ID）を指定すると、データの正規性を確かめたうえで検定を選んで実行します。記述統計量、グラフ、論文用の記述テンプレート、JASP の R コンソールで再現するコードまでを一度に出力します。

02できること

  • 2群：t検定（対応あり／Student・Welch）または Mann-Whitney の U 検定・Wilcoxon の符号付順位検定を自動選択
  • 3群以上：分散分析（一元配置・反復測定）または Kruskal-Wallis 検定・Friedman 検定を自動選択し、事後検定の候補を示す
  • 記述統計量の表と、群ごとの分布の図
  • APA 形式の記述テンプレートと、JASP の R コンソール用の再現コード

03使い方

  1. CSV ファイルを読み込む
  2. 比較する値（複数可）を選ぶ
  3. 群分けの列（対応なし）か ID の列（対応あり）を指定する
  4. 「統計分析を実行する」を押す

04読み込めるデータ

CSV（1行目が変数名）。横持ち（1列＝1条件）と、値の列＋群の列の形のどちらでも使えます。

05書き出せるもの

  • 解析レポート
  • 記述統計量
  • グラフ
  • APA 形式の記述テンプレート
  • R コード

06注意

  • 検定の選択は自動判定です。研究計画にもとづく検定があるときは、そちらを優先してください。
  • 3群以上のノンパラメトリック検定と事後検定の詳しい数値は、出力される R コードで確認してください。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
