ネットワーク分析ラボ

Social Network Analysis

「誰と誰がつながっているか」を貼るだけで、中心性・コミュニティ・構造指標を図と表と解説に。

ツールを開く

01概要

人と人、組織と組織などの関係データから、中心性・コミュニティ・ネットワーク全体の構造指標をまとめて計算します。ネットワーク図は動かして見やすく整えられ、結果の読み方、論文の記述例、R コードも出力します。

02できること

  • エッジリスト・隣接行列の読み込み（有向・重み付きに対応）
  • 次数・媒介・近接・固有ベクトル中心性、PageRank
  • コミュニティの検出と色分け
  • 全体の特徴・個人の指標・コミュニティの表、結果の読み方、論文の記述例、R コード
  • ネットワーク図を PNG・SVG、指標を CSV で保存

03使い方

  1. 関係のデータを貼り付けるかファイルを選ぶ
  2. 有向か、重みを使うかを指定して「分析する」
  3. 図の見え方（丸の大きさ・色）を調整する
  4. 下のタブで指標や記述例を確認する

「学級の相談相手」「共著ネットワーク」の例があります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

エッジリスト（1行に1つの関係：送り手, 受け手, 重み）または隣接行列。カンマ・タブ・空白区切り。

05書き出せるもの

  • ネットワーク図（PNG／SVG）
  • 指標の CSV
  • 結果の読み方
  • 論文の記述例
  • R コード

06注意

  • 自分自身への線（自己ループ）は取り除いて計算します。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
