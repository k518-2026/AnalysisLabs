混合モデルラボ

Linear Mixed Models

生徒が学級に、測定が個人に入れ子になったデータを、固定効果とランダム効果に分けて推定する。

ツールを開く

01概要

観測が群に入れ子になっているデータ（マルチレベルデータ）のための線形混合モデルです。2レベル・3レベル、経時データに対応し、群平均中心化、交互作用、ランダム傾きを指定できます。

02できること

  • 2レベル・3レベル（入れ子）のモデル
  • 連続量の中心化（全体平均・群平均）と交互作用
  • ランダム切片・ランダム傾き、切片と傾きの相関
  • REML／最尤法による推定
  • 群ごとの効果、診断、レポート

03使い方

  1. データを貼り付けるかファイルから読み込む
  2. 目的変数と群変数（Lv.2、必要なら Lv.3）を選ぶ
  3. 固定効果・交互作用・ランダム効果を指定する
  4. 「推定する」を押し、iii〜vi のタブで結果を見る

「学級に属する生徒」「同じ人を6回測る」「学校→学級→生徒」の例があります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV・タブ区切り（1行＝1観測、1列＝1変数）。群を表す列（学級 ID など）が必要です。

05書き出せるもの

  • 固定効果・ランダム効果の推定値
  • 群ごとの効果
  • 診断
  • レポート

06注意

  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
