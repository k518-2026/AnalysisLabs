メタ分析ラボ

Meta-Analysis

複数の研究の効果量をそろえて統合し、森林プロット・異質性・出版バイアスを吟味する。

ツールを開く

01概要

研究ごとの数値を入力し、共通の効果量にそろえて統合します。変量効果・固定効果、τ² の推定法、Hartung–Knapp 法を選べ、サブグループ、メタ回帰、一件ずつ抜いた分析、出版バイアス、累積メタ分析で結果を吟味します。

02できること

  • 効果量：Hedges の g、平均差、相関係数、オッズ比、リスク比、リスク差、直接入力
  • 変量効果／固定効果、REML・DerSimonian–Laird・Paule–Mandel、Hartung–Knapp
  • 森林プロットと予測区間（SVG 保存）
  • サブグループ比較、メタ回帰、一件ずつ抜く分析
  • 出版バイアスの検討、年次の累積

03使い方

  1. 効果量の種類を決める
  2. 研究の数値を貼り付けるか入力する（または例のデータ）
  3. 原典と照合してデータを確かめる
  4. 効果量をそろえて統合する
  5. 異質性や出版バイアスを吟味する

例のデータがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

表計算ソフトから貼り付け（カンマ・タブ区切り、1行目は見出し）、または画面で入力。

05書き出せるもの

  • 森林プロット（SVG）
  • 統合結果と異質性の指標
  • 吟味の図表

06注意

  • 論文 PDF から数値を読み取る機能は Claude 上で開いたときだけ動くため、この公開版では使えません。数値は手で入力するか貼り付けてください。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
