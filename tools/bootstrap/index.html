ブートストラップ解析

Bootstrap Resampling

データを復元抽出で繰り返し、平均値・中央値・標準偏差の信頼区間を経験的に求める。

ツールを開く

01概要

データから復元抽出を何千回も繰り返し、統計量の分布から信頼区間（パーセンタイル法）を求めます。1群の推定と2群の差に対応し、結果の読み方、論文の記述例、JASP の R コンソール用コードを出します。

02できること

  • 1群の推定／2群の差
  • 統計量：平均値・中央値・標準偏差
  • 再標本化の回数（1,000〜50,000）と信頼水準（90・95・99%）
  • 結果の読み方、方法・結果の記述例、R コード

03使い方

  1. CSV をドロップするか貼り付けて読み込む（またはサンプル）
  2. 解析モード・対象列・統計量を選ぶ
  3. 回数と信頼水準を決めて実行する

サンプルデータがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV または貼り付け（先頭行を列名にできる）。2群の差では各群を別の列に。

05書き出せるもの

  • 信頼区間と分布の図
  • 論文の記述例
  • R コード

06注意

  • 回数を増やすほど推定は安定しますが、計算時間が長くなります。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
