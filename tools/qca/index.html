質的比較分析（QCA / fsQCA）

Qualitative Comparative Analysis

少数事例の「条件の組み合わせ」と結果の関係を、真理表と論理式で示す。crisp・多値・ファジィ集合に対応。

ツールを開く

01概要

事例ごとの条件と結果から真理表を作り、Quine–McCluskey 法で主項を導き、被覆表を全探索して最小の条件式を求めます。一貫性（consistency）と被覆度（coverage）も計算します。

02できること

  • crisp QCA・多値 QCA・fsQCA（0〜1 のファジィ集合スコア）
  • 一貫性の閾値の設定、結果（Outcome）の反転
  • Quine–McCluskey 法による主項の導出と被覆表の全探索
  • Ragin の consistency／coverage
  • 結果を Markdown・PDF で保存

03使い方

  1. CSV を読み込む（またはサンプルを読み込む）
  2. ID 列・結果の列・条件の列を指定する
  3. fsQCA にするか、一貫性の閾値を決める
  4. 「解析を実行」を押す

crisp と fsQCA のサンプルがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV（1行が1事例）。crisp は 0/1、多値は整数、fsQCA は 0〜1 のスコア。

05書き出せるもの

  • 真理表
  • 解の式と consistency／coverage
  • Markdown・PDF

06注意

  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
