共起ネットワーク比較ラボ

Co-occurrence Network Comparison

2つのテキストの共起ネットワークを描き、共通の語・固有の語を色分けして比べる。

ツールを開く

01概要

2つのテキストを読み込み、同じ文や近くに出てくる語の関係を共起ネットワークとして描きます。共通する語・共起ペアと、それぞれに固有の語を色分けし、重ね合わせた比較ネットワークと類似度を示します。

02できること

  • 形態素解析：内蔵の簡易モード／kuromoji.js による高精度モード
  • 共起の単位（文・スライド窓）、品詞、ストップワード、表示する語数の設定
  • ネットワーク A・B と重ね合わせの比較ネットワーク（PNG 保存）
  • ワードランキング、共通語、共通の共起ペア
  • 円や線をクリックすると、その語（組）を含む元の文を表示
  • 複合語のまとめ・否定のむすびつけ（任意）
  • 基準線と並べ替え検定（違いは偶然の範囲か）
  • 論文の記述例（方法・結果・考察）と R（RMeCab・igraph）のコード

03使い方

  1. テキスト A・B を入力するか .txt を読み込む（またはサンプル）
  2. 共起の単位・品詞・表示の条件を決める
  3. 「共起ネットワークを生成」を押す

「宇宙探査 vs 海洋探査」のサンプルテキストがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

テキスト（貼り付け、または .txt ファイル）。

05書き出せるもの

  • 共起ネットワーク（PNG）
  • ランキングと共通語の表
  • 論文の記述例
  • R コード

06注意

  • 簡易モードの品詞は字種と語尾からの推定です。
  • 高精度モードを選ぶと、辞書ファイルを CDN から取得します（テキストは送信されません）。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
