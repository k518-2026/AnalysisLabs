授業発話分析ラボ

Classroom Discourse Analysis

授業の逐語録から、フランダース相互作用分析・発問の分類・IRF 連鎖・語彙を数えて見せる。

ツールを開く

01概要

1行1発話の逐語録を貼ると、授業の相互作用を数え、図にし、文章にします。時刻が付いていれば待ち時間も測ります。自動分類は規則にもとづく推定なので、コード修正のタブで確認・修正できます。

02できること

  • FIAC（フランダース相互作用分析）
  • 発問の分類（開いた／閉じた × 認知レベル）
  • IRF（開始・応答・評価）の三部構造の連鎖
  • 特徴語・共起などの語彙分析
  • 授業の呼吸（時間の流れ）、基本統計

03使い方

  1. 逐語録を貼り付けるかファイルをドロップする（またはサンプル授業）
  2. 教師・沈黙とみなす話者名を指定する
  3. 「分析する」を押す
  4. 自動分類をコード修正タブで確認する

サンプル授業があります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

1行1発話。「話者：発話」の形（区切りは「：」「,」タブ）。行頭に 00:12:30 のような時刻を置くと待ち時間を測ります。.txt／.csv／.tsv。

05書き出せるもの

  • 各分析の図と表
  • コード修正後の結果

06注意

  • 自動分類は規則にもとづく推定です。研究に使うときは必ず確認してください。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
