傾向スコアマッチング

Propensity Score Matching

観察データで、処置を受けやすさが近い者どうしを組にして、処置の効果を推定する。

ツールを開く

01概要

共変量からロジスティック回帰で傾向スコアを求め、値の近い処置群と対照群を組にします。マッチングの前後で共変量のバランスを確かめ、処置の効果を推定します。

02できること

  • ロジスティック回帰による傾向スコアの推定（カテゴリ変数は自動でダミー化）
  • 1:1〜1:4、非復元／復元、キャリパー（ロジットの標準偏差の倍数）
  • マッチング前後のバランスの確認
  • 処置効果の推定と書き出し

03使い方

  1. データを読み込む
  2. 処置変数・アウトカム・共変量を決める
  3. マッチングの条件を選んで「推定して組にする」
  4. バランスと効果を確認し、書き出す

サンプルデータがあります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV・タブ区切り（1行目が変数名、1行が1ケース）。処置変数は2値。

05書き出せるもの

  • マッチング結果
  • バランスの表と図
  • 効果の推定値
  • 書き出し

06注意

  • アウトカムより後に起きた変数は共変量に入れないでください。
  • 傾向スコアで調整できるのは、測定した共変量だけです。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
