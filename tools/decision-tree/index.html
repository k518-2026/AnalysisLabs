決定木ラボ

Decision Tree (CART)

分類と回帰の決定木を育て、あたり具合・変数の重要度・ルールを確かめる。

ツールを開く

01概要

CART による決定木を、分割の基準や深さを変えながら育てます。樹形図のノードを押すとその中のデータの内訳が見え、検証用データでのあたり具合、深さと精度の関係、変数の重要度、葉までのルールを確認できます。

02できること

  • 分類（ジニ不純度／エントロピー）と回帰
  • 最大の深さ・最小サンプル数・検証用の割合・乱数の種を設定
  • 樹形図、分割表、深さと精度の関係（過学習の見きわめ）、変数の重要度、ルール一覧
  • 値を入れて予測し、たどった枝を表示
  • 論文の記述例（和文・英文）と rpart の R コード

03使い方

  1. CSV・TSV を読み込む（またはサンプルを選ぶ）
  2. 目的変数と説明変数を選び、分類か回帰かを決める
  3. 木の育て方を設定して「決定木を育てる」
  4. A〜H のタブで結果を確認する

「アヤメ（分類）」「解約予測（分類）」「店舗売上（回帰）」があります。

04読み込めるデータ

CSV・TSV ファイル、または貼り付け。

05書き出せるもの

  • 樹形図（SVG／PNG）
  • ルールの文章
  • 論文の記述例
  • R コード

06注意

  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
