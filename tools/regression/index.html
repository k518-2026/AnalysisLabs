説明・予測する

回帰分析・自動判定

Auto Regression

目的変数と説明変数の型から、重回帰・ロジスティック回帰・数量化I類／II類を自動で判定する。

ツールを開く

01概要

目的変数と説明変数を選ぶと、それぞれの型（量的／2値）から分析の種類を判定し、予測式と論文の記述例を作ります。分散分析表・標準化係数・VIF などの詳しい数値は、出力される R コードで求めます。

02できること

  • 分析の種類の自動判定：重回帰／ロジスティック回帰／数量化I類（ダミー重回帰）／数量化II類
  • 予測式
  • APA 形式の記述例
  • 詳しい統計量（分散分析表・標準化係数・VIF など）を出す R コード

03使い方

  1. CSV ファイルを読み込む
  2. 目的変数を1つ、説明変数を複数選ぶ
  3. 投入方法（強制投入法／ステップワイズ法）を選ぶ
  4. 「分析を実行する」を押す

04読み込めるデータ

CSV。計算に使う列は半角数字だけにしてください（「100点」「1,000」などは計算できません）。

05書き出せるもの

  • 予測式
  • 論文の記述例
  • R コード

06注意

  • ステップワイズ法とロジスティック回帰では、ブラウザー上の予測式は省略し、R コードで計算します。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
