主成分分析ラボ

Principal Component Analysis

たくさんの変数を少ない軸にまとめ直す。固有値からバイプロット、記述例まで。

ツールを開く

01概要

変数を選んで実行すると、固有値と寄与率、主成分負荷量、主成分得点、バイプロット、論文での記述例までを順に出します。

02できること

  • 相関行列（標準化）／分散共分散行列
  • 主成分の数の決め方：固有値1以上・累積寄与率・個数指定
  • 回転なし／バリマックス回転
  • スクリープロット、バイプロット（グループで色分け）
  • 主成分得点、論文の記述例

03使い方

  1. CSV・TSV を読み込むか貼り付ける（または例を選ぶ）
  2. 変数、ケース名の列、色分けの列を選ぶ
  3. 行列・主成分の数・回転を決める
  4. 「主成分分析を実行」を押す

「学力テスト」「商品評価」の例があります。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV・TSV（1行目に変数名、1列目に ID や氏名）。

05書き出せるもの

  • 固有値と寄与率
  • 主成分負荷量・主成分得点
  • 図（PNG）と表（CSV）
  • 論文の記述例

06注意

  • 欠測のあるケースは分析から除きます（除いた件数を表示します）。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
