ノンパラメトリック検定

Nonparametric Tests

順位にもとづく検定を、データ入力から論文の記述例・R コードまでひと続きで。

ツールを開く

01概要

正規分布を仮定しにくいデータや順序尺度のデータに使う、順位にもとづく検定をまとめたツールです。変数の型は自動で判定し、プレビュー表で直せます。結果に合わせた論文の記述例と R コードのひな型を出します。

02できること

  • CSV・タブ区切りの読み込みと、列の型（数値／カテゴリ）の自動判定
  • 対応なし・対応ありの検定
  • 結果にもとづく論文の記述例（APA 風の日本語）
  • 検定に対応する R コードのひな型

03使い方

  1. データを貼り付けて読み込む（またはサンプルを入れる）
  2. 検定を選び、変数を指定する
  3. 「検定を実行する」を押す
  4. 記述例と R コードを確認する

サンプルデータを入力できます。まずはそれで動きを確かめるのがおすすめです。

04読み込めるデータ

CSV またはタブ区切り（1行目が変数名、1行が1ケース）。対応のある検定では同じ行を同じ対象として扱います。

05書き出せるもの

  • 検定結果
  • 論文での記述例
  • R コード

06注意

  • 近似計算を用いる検定は、結果欄にその旨が表示されます。
  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
