クラスター分析ラボ

Cluster Analysis

階層的クラスター分析と k-means 法で、似たものどうしをまとめる。樹形図の切断線はドラッグで動く。

ツールを開く

01概要

データを読み込み、階層的クラスター分析か k-means 法で似たケースをまとめます。樹形図の切断線をドラッグすると、クラスター数と色分けがその場で切り替わります。

02できること

  • 階層的クラスター分析（ウォード法・群平均法・最遠隣法など7種）
  • k-means 法（初期値を変えて繰り返す）
  • 距離：ユークリッド・平方ユークリッド・マンハッタン・相関・コサイン
  • 樹形図、布置図、クラスターの特徴、ケース一覧、分け方の検討、結果の読み取り

03使い方

  1. ファイルを読み込む（またはサンプルを選ぶ）
  2. ケース名の列と、分析に使う変数を選ぶ
  3. 変数のそろえ方・手法・距離・結合法を決める
  4. 「分析する」を押す

「花の計測」「学習者調査」「地域指標」があります。

04読み込めるデータ

CSV・TSV・TXT、または貼り付け。

05書き出せるもの

  • 樹形図・布置図
  • クラスターの特徴
  • 書き出し

06注意

  • 計算はブラウザーの中で行われ、入力したデータがサーバーに送られることはありません。
  • 出力される記述例や R コードは下書きです。数値と解釈は、研究の文脈と照らし合わせて確かめてください。
